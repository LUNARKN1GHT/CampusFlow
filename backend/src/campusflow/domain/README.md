# 领域层

保存不依赖 Web、数据库和模型服务的业务对象与规则，只使用 Python 标准库、数据类和枚举。

当前模块：

- `states.py`：核对状态（ReviewStatus）与任务执行进度（TaskProgress）两套独立状态枚举，以及优先级、日程重复规则
- `dates.py`：截止时间规则——只有日期的 DDL 保持日期精度，不伪装成午夜或 23:59
- `semesters.py`：学期日期范围校验
- `schedule.py`：固定日程与可用时间段校验
- `errors.py`：领域错误（API 层转换为 400/404 响应）

后续按里程碑加入信息核对状态机、时间块、依赖与冲突检测等模块。正式截止时间与个人计划时间必须分开建模；日期换算、约束检查与排期可行性由确定性代码验证，模型输出不能直接成为已确认事实或执行授权。
