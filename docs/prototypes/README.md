# CampusFlow M0 交互原型

本目录保存 Issue #42–#44 的无后端 HTML 原型，用于确认字段、状态和关键动作，不代表产品功能已经实现。

直接用浏览器打开对应文件即可评审：

- `import-source.html`：资料导入、处理状态、原文与引用定位。
- `review-qa.html`：集中核对、字段修正、引用和资料不足问答。
- `tasks-plan.html`：任务、两周计划草案、容量缺口和时间块调整。

原型使用合成内容，不发送请求、不读取本地资料，也不会执行删除、同步或计划接受等真实操作。页面宽度低于 900px 时自动改为单栏，主要控件可通过键盘操作。
