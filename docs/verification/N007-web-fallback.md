# N007 网页不可访问时的替代输入

作者：李亦凡；任务 #163；父任务 #18。依赖 N006 #159、D004 #81。

## 已实现的界面行为

资料库导入面板新增「公开网页」入口，请求仍由 N005 的 `POST /api/v1/materials/web` 完成。界面只提交用户填写的公开网址、标题、发布信息和适用范围，不携带账号、Cookie 或登录表单，也不会自动登录教务系统或绕过登录/反爬验证。

读取失败时保留后端返回的中文原因，并显示固定的未覆盖范围说明：

> 网页正文未导入：<原因>。可粘贴可访问的原文或上传已保存的文件；未覆盖内容不会被当作“没有要求”。

失败后提供两个替代入口：

- 改为粘贴原文：切到文本导入，保留标题、发布方、发布时间、学期、课程与教学班，用户粘贴当前能看到的原文后按普通文本保存。
- 改为上传文件：切到文件导入，保留学期、课程与教学班，用户上传已保存的 PDF、图片或 DOCX。

异步解析阶段才发现登录表单时，资料列表的失败/部分成功区域同样为网页资料提供「粘贴网页原文」与「上传网页文件」，并展示作业返回的失败原因。

## 验收条件对应

| 验收条件 | 证据 |
| --- | --- |
| 不自动登录教务系统 | 前端不提供账号/Cookie 输入；N004 抓取器只发匿名 GET，且既有 `tests/test_web_import.py::test_unauthenticated_request_never_fetches` 验证未登录请求不会触发抓取。界面同时显示“不会自动登录教务系统”的说明。 |
| 失败原因和未覆盖范围可见 | 失败响应原因原样显示；`fallbackNotice` 明确“网页正文未导入”和“未覆盖内容不会被当作没有要求”；异步登录页失败在资料行显示处理作业原因。 |

backend$ uv run --locked pytest tests/test_web_import.py tests/test_word_upload.py -q

Playwright 用固定 400 响应模拟“需要登录或拒绝访问”，检查失败原因、未覆盖范围、替代按钮以及标题与范围保留。未调用真实外站，也未验证任意学校的反爬页面识别。

## 未覆盖与限制

- 抓取器把 401/403 作为访问拒绝；返回 200 的登录页由 N006 解析器在异步作业中识别，识别范围仅限包含密码输入或登录表单的页面，不保证覆盖所有登录门户或反爬机制。
- 替代输入会作为新的资料保存，不会把粘贴内容合并回原网页快照；原失败请求不留记录（见 `test_web_import.py::test_network_failure_leaves_no_partial_record_or_file`）。
- 未实现真实教务系统登录、验证码处理或自动重试。
