# A011 验证按截止精度与核对状态生成提醒

作者：李亦凡；任务 #187；父任务 #21。前置 #182（A010）、R003、T008。

## 覆盖场景

1. **仅日期 DDL**：提醒正文明确“未指定具体时刻”，不出现 `00:00`／`23:59`，`payload.date_only=true`、`due_time=null`；内部投递时间不冒充课程截止时刻。
2. **来源失效**：任务原截止来自资料时先生成确定截止提醒；资料删除并保留任务后，待发送的截止提醒被撤消，改为一条“来源资料已失效、截止要求待核对”的提醒，正文不再出现“将在 … 截止”的确定表述。
3. **待核对事项**：存在待核对候选时生成工作空间级提醒，带待核对数量，并说明确认前不会作为确定约束参与排期；同日重复读取不重复生成。
4. **核对状态变化**：候选确认后不再生成新的待核对提醒；已发送的提醒保留为历史记录，不静默改写。

## 修复

- 工作空间级“待核对”同步原先会撤消所有 `review` 类型的待发送提醒，包括任务来源失效提醒。现仅撤消 `task_id IS NULL` 的工作空间级提醒，任务级提醒保留。
