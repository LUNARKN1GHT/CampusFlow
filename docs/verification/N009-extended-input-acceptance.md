# N009 验收扩展输入到引用问答的链路

作者：李亦凡；任务 #172；父任务 #18。依赖 N008 #167、Q018 #161。

## 验收范围

使用 N001 合成样本检查三条链路：

1. Word 通知（`word-notice-paragraph.docx`）→ 上传 → 异步解析 → 索引 → 带引用问答。
2. 公开网页（`public-notice.html`）→ 快照导入 → 异步解析 → 索引 → 带引用问答；随后原站内容变化并再次导入。
3. 登录页（HTTP 成功但只有密码表单）→ 解析失败，不生成正文片段。

## 已核对的结果

| 检查项 | 结果 |
| --- | --- |
| 无依据页码不被补造 | Word 片段与回答引用均 `page is None`，使用 `paragraph:7` 定位；网页片段与引用使用 `web:p:3`，`page is None`。 |
| 无依据发布时间不被补造 | 两种导入未提供完整发布时刻时，资料 `published_at is None`；网页页眉中的“2026-11-20”只作为原文片段保留，抓取时间单独记录在版本来源元数据。 |
| 回答依据可定位 | Word 回答引用指向包含“2026-11-15 18:00”的原文摘录，引用校验为有效且无“日期未出现在被引原文”提示；网页回答引用指向包含“12 月 19 日至 12 月 27 日”的片段。 |
| 原站变化后旧快照仍可核对 | 同一网址重新抓取并导入新内容后，旧资料的片段、原文文件和引用摘录保持不变，旧引用仍为有效。 |
| 失败样本不伪造依据 | 登录页解析后资料为失败、片段为空，且没有发布时间。 |
