# A008 依赖、子任务与局部调整界面

作者：李亦凡；任务 #207；父任务 #20。前置 #180（A004）、#203（A006）、#204（A007）、#196（P016）。

## 已实现

计划页（`/plan`）：

- 规划区间选择：今天、本周、未来两周、自定义起止日期；自定义日期在非自定义区间下禁用。
- 「保留锁定块重排」按钮调用 A005 接口；生成结果仍为待接受草案。
- 变化检测面板展示调整建议、受影响任务和“当前计划尚未修改”，用户点击后才生成本地调整草案。
- 时间块标注「保留安排」或「新安排 / 移动」，并显示锁定状态。
- 接受前展示预览统计：保留段数、新安排或移动段数；接受后显示“当前计划与刚才预览一致”。

任务页（`/tasks`）：

- 顶部依赖检查面板展示成环、范围外/缺失前置、已取消前置与阻塞任务。
- 每项任务新增「依赖与子任务」入口：
  - 展示父任务汇总（子任务数、预计/剩余耗时、完成百分比）；
  - 增删前置依赖，展示后续任务；
  - 展示并编辑子任务，生成只读拆分建议后可直接修改标题/耗时再批量创建。

API 客户端补充任务关系、子任务、依赖检查、重排与调整建议类型和调用。

## 验收对照

| 验收条件 | 证据 |
| --- | --- |
| 用户能看见保留与移动的块 | 计划页按任务与起止时间对比当前计划，标记「保留安排」或「新安排 / 移动」；后端保留块另带 `preserved` 约束来源。 |
| 确认后的调整与预览一致 | 接受前显示保留/移动段数；接受动作只提交当前草案版本，接受后显示与预览一致的段数。后端 `tests/test_planning_reschedule.py` 与 `tests/test_planning_adjustments.py` 验证接受前后计划版本与时间块一致。 |
| 依赖与子任务可见 | 任务页依赖检查面板与任务关系面板；拆分建议标为可编辑建议，确认后才创建。 |

## 未覆盖与限制

- 浏览器验证覆盖页面加载与关键面板显示；带真实任务数据的完整点击流程由 A009 的端到端用例覆盖。
- 依赖只能按任务编号添加，尚未提供搜索选择器。
- 界面不直接调用通知差异接口；调整建议来自排期输入变化。
