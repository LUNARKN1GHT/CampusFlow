# #554 文本导入后的事项提取与问答准备

日期：2026-11-05。作者：金嘉睿。关联 Issue #554，依赖本地 #553、#555、#556 修复。

## 行为

- 粘贴文本界面默认勾选“整理事项并准备问答”，有模型费用提示；可取消，只保存原文。
- `POST /materials/text` 的 `process_ai` 默认 false，兼容既有调用方；true 时资料、片段、
  提取作业及索引作业同事务保存，再尝试投递。队列不可用不丢已保存内容。
- `POST /materials/{id}/process` 为既有原文补建缺少的作业；版本行锁避免并发重复创建。
- 复用任务、固定活动、规则三类既有提取器，结果原子保存到待核对；不直接创建正式事项。
- 模型调用期间不占用数据库事务。写回前核对领取时间、来源和适用范围，阻止超时旧结果、
  删除、归档、改班等情况写入。重复执行已完成作业无副作用。
- 桌面数据库 Worker 和服务端 RQ 均增加提取入口；RQ 复用解析队列。
- 失败文案不返回服务商原始异常；配置问题可在设置修正后手动重试。
- 新文本保存解析覆盖记录；历史缺少记录的资料保留覆盖不明提示，不宣称完整可问答。
