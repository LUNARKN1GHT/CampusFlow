# #556 模型配置失败的人工恢复

缺少图片密钥及旧版索引请求失败现在提供“检查 AI 服务设置后手动重试”入口。
新索引在缺配置时直接记录明确原因，不再把每块标为无效响应。
后台不会自动重复尝试缺配置的作业。手动恢复前检查当前密钥、来源版本及归档状态。

旧索引恢复只重置当前清单中无效响应的失败块，保留成功向量、其他配置的结果和历史尝试。
损坏图片、来源删除、被新版本替代及已归档资料不因此获得处理资格。
旧索引通用错误无法证明当时一定缺密钥，因此入口要求检查配置，不声称已确定原始原因。
