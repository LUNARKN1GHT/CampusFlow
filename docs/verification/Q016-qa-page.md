# Q016、Q017 问答页面与来源失效提示

日期：2026-10-18

## 页面能力

- 侧栏新增“智能问答”，路由 `/qa`。页面提供学期、课程、教学班、排序方式与历史会话选择。
- 答案正文与引用卡片分开显示；引用卡展示资料标题、定位（页码/段落）、版本号与原文摘录。可验证引用点击后跳转 `/library?material=&version=&chunk=`，由资料库按版本与片段定位原文。
- 已失效引用不可点击，显示“已失效”与原因；会话顶部汇总失效引用数量，并提供进入资料库的入口。
- 无依据状态独立展示，明确“现有资料中未发现”，并提供“补充资料”“查看待核对”入口；加载失败由 `ApiFeedback` 单独展示。
- 部分覆盖、索引不可用、尚未索引分别用提示条展示；待核对冲突数量可跳转 `/review`。

## 验收证据

- 类型检查与构建：`cd frontend && npm run build`，通过（vue-tsc + Vite）。
- 本地浏览器走查（2026-10-18，临时确定性假模型，不产生付费调用）：
  1. 登录后进入 `/qa`，学期/课程/教学班选项来自真实 API；
  2. 选择“数据库原理 · CS101 / 一班”并提问，返回答案与 1 张可验证引用卡；
  3. 点击引用卡跳转 `/library?material=1&version=1&chunk=2`，资料库按版本/片段定位；
  4. 无资料时显示“现有资料中未发现足以回答的依据”，不是“没有作业”；
  5. 覆盖提示条与“尚未索引”说明可见。
- 后端接口行为见 [Q011-qa-protocol.md](Q011-qa-protocol.md) 与 [Q014-conversations.md](Q014-conversations.md)。

## 限制

- 浏览器走查使用假模型验证交互与状态展示；真实模型回答质量需配置密钥后按 Q018 样本复核。
- 未做移动端真机测试；页面沿用现有响应式布局。
