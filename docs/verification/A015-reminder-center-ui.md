# A015 验证提醒中心与规则设置界面

作者：李亦凡；任务 #213；父任务 #21。前置 #208（A014）、P018。

## 页面能力

- 路由 `/reminders`，导航「提醒」；按全部／未读／已读筛选。
- 列表展示提醒类型、状态、计划时间与任务入口；`sent` 且未读可标为已读，待发送或已发送可忽略。
- 摘要展示未读、待发送、已发送、已忽略、已撤销数量。
- 默认规则表单：提前量、重复间隔、暂停、启用；无自定义默认规则时显示内置策略，保存后创建或更新默认规则。
- 任务单独规则：列表展示版本、暂停/停用状态，可编辑、暂停/恢复、删除；可为尚无规则的任务新建。
- 空状态固定提示「没有提醒不代表没有待办或冲突，请以任务列表与冲突检查为准」。

## 交互与数据边界

- 所有写操作完成后重新读取提醒与规则，以服务端状态为准；失败显示错误并保留表单内容。
- 提醒只提示，不修改任务 DDL、核对状态或计划块。
- 时间按工作空间时区生成，界面按本机时区显示；仅有日期的 DDL 额外注明“不表示具体时刻”。
