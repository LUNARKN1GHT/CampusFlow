# Windows 加密文件写入重试修复

日期：2026-11-13。作者：金嘉睿。

## 问题与修复

中文路径修复验收时，Windows 偶发拒绝替换加密凭据文件，首次启动因而退回文件保存。
此前 200 轮合成凭据测试出现 12 次 WinError 5，等待 0.2 秒后重试均恢复。
用户已选择短暂等待、有限重试；具体文件占用者未确定。

- 只对 Windows 错误码 5、32、33 重试替换，最多尝试 6 次、等待 5×0.2 秒。
- 重试复用同一份已生成的密文临时文件，继续整体替换，不在旧文件上逐字覆盖。
- 持续失败明确报错，已有加密文件保持不变；其它磁盘错误立即上报。
- 首启和凭据恢复遇到 Windows DPAPI 存储或校验失败，不再自动降级到明文文件，
  也不删除仍可能有效的既有加密条目。显式选择 file 的历史配置不在本轮自动迁移。
