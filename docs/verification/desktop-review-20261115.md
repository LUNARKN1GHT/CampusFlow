# 桌面启动中断与凭据复审

日期：2026-11-15。作者：金嘉睿。

## 本轮发现与修改

1. 初始化过程中调用停止，旧逻辑可能在 bootstrap 返回之前就报告停止；晚到的初始化结果仍可能启动数据库。
   修改后停止流程等待在途初始化收尾，再确认数据库回收、清空内存凭据、报告停止。
   停止中收到新启动请求会等停止完成再启动。新增受控延迟测试验证不提前停止、只回收一次、未启动 API/Worker。
2. JSON 凭据文件重复记录同一账户时，默认解析会保留最后一条，之后保存可能丢失前一条。
   修改为发现重复记录即报错，读取、保存、删除都不改动原文件。新增三个回归场景。

同时保存 11 月 13 日尚未提交的复审修复：重复启动保护、损坏条目保护、必需数据库工具完整性检查、中文副本目录不复用。
