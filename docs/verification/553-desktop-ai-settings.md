# #553 桌面 AI 设置

设置页新增 AI 服务设置：智谱/DeepSeek 文字型号、智谱图片型号及密钥，分别展示文字、图片、检索配置状态。沿用已有向量型号与维度，避免混用已有索引。

配置通过现有凭据存储保存在数据目录的 `ai-settings` 子目录；macOS 使用带数据目录身份的钥匙串记录，Windows 自动使用 DPAPI。服务端模式只读，仍由环境配置管理。页面不回显密钥，留空保留、勾选清除后明确覆盖环境中的旧值。

API 与常驻 Worker 在新调用时读取同一记录，无需重启；已开始的调用可能继续使用旧配置。保存不发起模型调用，也不自动恢复已有失败作业（#556）。连接检查逐能力执行，仅发送合成样本，必须显式确认可能产生费用。返回固定错误类别，校验错误不回显输入。

关键词问答复用已建立索引，不再额外调用查询向量模型；建立原文索引仍需要向量模型。没有候选不等于资料中没有事项。
