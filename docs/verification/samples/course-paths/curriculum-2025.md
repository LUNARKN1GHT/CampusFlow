## 5. 预期结论

| 项目 | 预期 |
| --- | --- |
| 完整拓扑排序 | **不可得出**。阻塞原因：强制先修环、自环、方案外先修课程、来源矛盾 |
| 强制先修环 | CS401 → CS402 → CS403 → CS401；必须返回具体路径，不能只报“有环” |
| 自环 | CS404 → CS404；必须显式报告，不能静默丢弃该关系 |
| 缺项 | CS499 不在方案课程表；CS405 受影响，必须列出缺失节点与引用来源 |
| 来源矛盾 | CG-2025-001 两条断言并列展示，核对前阻塞“图完整”的结论 |
| 未阻塞子图 | 去掉 CS401–CS405、CS499 和冲突对后，其余课程可排序；示例顺序与 2024 版相同 |
| 未知字段 | CS215 学分与开课学期仍未知，CS209 开课学期仍未知；只提示，不影响依赖顺序 |
| 并修 | 不参与拓扑排序，只提示同学期修读 |
| 建议先学 | R-2025-024 与冲突共存，不能当作已确认的软约束；冲突未核对前不按建议先学处理 |
| 版本范围 | 本版关系不得套用到 2024 版的同名课程；2024 版的建议先学也不得用来“解决”本版冲突 |

CS101 → CS102 → CS111 → CS112 → CS203 → CS201 → CS202 → CS204 → CS205 → CS206 → CS212 → CS213 → CS207 → CS208 → CS209 → CS210 → CS211 → CS214 → CS215。

该顺序只说明未阻塞部分可排序，不代表整份 2025 修订版已可执行，也不代表已满足毕业或选课要求。
