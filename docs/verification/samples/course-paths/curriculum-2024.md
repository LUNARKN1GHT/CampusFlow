## 4. 预期结论

| 项目 | 预期 |
| --- | --- |
| 强制先修图 | 有向无环，可给出完整拓扑顺序 |
| 完整顺序示例 | CS101 → CS102 → CS111 → CS112 → CS203 → CS201 → CS202 → CS204 → CS205 → CS206 → CS212 → CS213 → CS207 → CS208 → CS209 → CS210 → CS211 → CS214 → CS215 |
| 每条强制先修 | 上述顺序中先修课程均排在受限课程之前，必须逐条满足 |
| 并修 | 不参与排序；示例顺序把 CS212、CS213 相邻放置，仅为展示，不是排序要求 |
| 建议先学 | 示例顺序恰好满足两条建议；即使不满足也只提示 |
| 未知学分／开课学期 | CS209、CS210、CS211、CS215 保留未知状态；可给出依赖顺序，但不能声称已排出可执行的学期方案 |
| 范围 | 本方案的关系只在 2024 版内生效，不得套用到 [2025 版](curriculum-2025.md) 的同名课程 |
