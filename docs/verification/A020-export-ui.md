# A020 导出预览与下载界面

作者：李亦凡；任务 #214；父任务 #22。前置 #209（A018）、#210（A019）。

## 范围

- 新增 `/export` 页面与导航「导出」：先显式勾选任务或选择已接受计划，再选择格式与选项，预览后才能下载。
- 任务模式支持搜索，但搜索结果不自动成为范围；空选择直接提示，不提供整空间导出。
- 计划模式只列出 `status=accepted` 的计划；没有已接受计划时提示先去计划页接受，不自动接受草案。
- 预览展示源对象数、输出条数（CSV 行／ICS 事件）、日期范围、时区、计数、排除项、警告与逐条内容；来源失效任务保留并标注来源提示已省略。
- 下载携带预览返回的 `scope_fingerprint`；范围、格式、勾选或选项变化时旧预览立即失效。服务端返回 409 时清空预览并提示重新预览。
- 文件名读取 `Content-Disposition`，缺失时按日期回退；下载完成后提示文件只保存到本机、服务端不保留。
- 计划模式当前只提供 ICS；切到计划模式会自动切换格式并禁用 CSV，避免请求一个明确不支持的组合。
- ICS 页面明确说明：文件只是草案，尚未写入外部日历，不会发送消息或自动同步；接受新计划后可能产生重复事件，建议先删除旧事件。
