# C008 个人方案、别名与修读状态界面

## 交付内容

- 新增「课程路径」页面与导航入口（`frontend/src/views/CoursePathsView.vue`）。
- 当前适用方案版本在页面顶部显著展示；缺少专业、年级或方案时列出 `missing_fields`，不推断。
- 方案版本列表支持新建、查看与设为当前方案；切换前调用 `switch-preview`，展示当前方案的课程数、关系数、修读记录数与“不删除、不迁移”的说明。
- 课程目录：新增、编辑、删除课程，维护代码、学分与开课季节；未知学分/季节保持空。
- 课程关系：按三类关系分别展示与保存，建议先学只作提示；来源候选可跳转待核对页。
- 别名：维护课程别名及教学班/学期范围，并提供只读名称解析，歧义时不自动选择。
- 修读状态：保存已修/在修/待修记录、学期、成绩与已获学分；汇总按已完成 > 在修 > 待修 > 未知展示，未填写的成绩/学分保持空。

## 验收对应

| 验收条件 | 实现与证据 |
| --- | --- |
| 当前方案版本显著可见 | 顶部“当前适用方案”标题显示专业、年级与版本；缺失信息单独提示 |
| 切换方案时提示受影响关系 | `switch-preview` 面板展示课程/关系/修读记录计数与数据保留说明；浏览器实测创建 2025 版后出现切换预览 |

## 验证记录

- `npm run build`：类型检查与构建通过。
- 浏览器实测（后端 8010 测试库、前端 5174）：
  - 登录后导航到「课程路径」，页面显示当前方案缺失提示与方案列表。
  - 新增课程“数据结构”（4 学分、秋季），列表即时更新。
  - 新增修读记录（已修、成绩 88），汇总从“未知 1”变为“已修 1”，未自动补已获学分。
  - 新建“2025 修订版”后出现“切换到 2025 修订版”面板，展示影响计数与数据保留说明；设为当前方案后页面切换到新版本。
- 修读状态接口来自 C007；未接入时页面明确显示“修读状态暂不可用”，不伪造状态。

## 边界

- C008 只维护方案与个人修读数据；关系图、环/缺项与修读顺序界面由 C015/C016 接入。
- 页面不宣称毕业资格或选课审核结果。
