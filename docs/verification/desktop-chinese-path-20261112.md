# 中文安装路径启动修复

日期：2026-11-12。作者：金嘉睿。

## 问题及实现

在包含“AI大作业”的安装目录首次启动，内置 PostgreSQL 初始化曾报
`invalid byte sequence for encoding "UTF8": 0xb4`。用户选择自动准备英文路径运行副本。

- Electron 在初始化数据库之前准备副本，将结果交给启动、停止、升级和备份使用的同一配置。
- 默认位置为 `%LOCALAPPDATA%\CampusFlow\pg-runtime`，支持 `CAMPUSFLOW_PG_RUNTIME_DIR` 覆盖。
- 只复制 `bin`、`lib`、`share` 和许可证，不复制 `pgdata`、资料或备份。
- 根据文件内容区分版本；先复制到临时目录，完整核对后才发布。重启复用完整副本；
  损坏副本、遗留临时目录不执行，旧副本不原地覆盖。
- 不同版本副本及损坏副本暂不自动删除，避免删除其他实例正在使用的文件。
- 英文安装路径及非 Windows 系统沿用原流程。默认缓存实际路径仍含中文时明确报错，
  需由维护人员指定可写的英文目录；尚未宣称支持所有中文 Windows 用户名环境。
