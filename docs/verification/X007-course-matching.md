# X007 课程教学班严格匹配

任务：[X007 #114](https://github.com/LUNARKN1GHT/CampusFlow/issues/114)，父 Issue #11。作者：金嘉睿（24151735）。2026-10-14。

用户选择严格匹配：只在选定学期核对课程名与教学班，不做简称、拼写纠正或近似推荐。本项不调用模型，无新增依赖、数据库迁移或配置。

## 调用与字段

`application.course_matching.match_candidate_course` 接收工作空间、资料/版本、候选草稿和显式选定的 `semester_id`。可信调用方提供带原文证据的 `course_name_text` / `class_name_text`，也可复用草稿已有的同名字段；没有输入则保留 null 与缺失原因。任务、活动、规则三类候选均可使用。

应用入口验证资料归属、归档状态、版本、输入全部证据及已有学期/课程范围。跨空间、跨版本或摘录不存在时拒绝返回结果，所选学期不符合资料范围时要求先核对范围。缺少学期时不检索全部学期。

输出保留原候选内容和 `scope`，增加原文字段及 `course_match`，不将建议课程写入 `scope.course_id`。原文字段必须是 document 文本且逐字包含于自身证据；原文存在并不证明语义关联正确，调用方仍须核对这段课程名/班级确实适用于当前事项。本项提供匹配入口，不新增原文字段的 AI 提取步骤。

`course_match` 保存所选学期、状态、建议课程 ID、完整匹配数量、可选数量、最多 20 个课程快照和 `options_truncated`。选项包含课程 ID、原名称、教学班、课程代码及教师，便于后续人工选择。数量限制只用于展示，严格匹配和唯一性判断始终使用完整学期集合；有剩余选项时可调用现有 `GET /api/v1/courses?semester_id=...` 查看所选学期全部课程。

有原文证据时结果标为 inferred，无课程/班级原文时仅为 suggestion。所有结果都附加人工核对提示。调用方显式使用 X001 `save_candidates` 后可原样保存、回读，仍为 pending，不创建正式 Task 或修改资料。重复匹配会重新查询课程目录并替换本用例的匹配字段/提示；省略课程名/班级参数表示复用原字段，要清空需显式提供值为 null 的原文字段。

## 匹配结果

| 状态 | 含义及操作 |
| --- | --- |
| missing_semester | 未选学期，无选项，不跨学期猜测 |
| missing_name | 缺课程名，不能只凭班级推定；提供所选学期课程供人工选择 |
| unmatched | 没有同名课程；保留原文，提供学期内课程作为人工选项而非近似推荐 |
| class_mismatch | 同名课程的班级不同或未记录；展示同名课程，不忽略原文班级要求 |
| ambiguous | 多个符合条件的记录；建议 ID 为空，保留多个选项 |
| unique_candidate | 只有一个记录符合输入条件；仅给建议，仍待核对且不修改 scope |
| scope_conflict | 原文与已有课程/班级范围冲突；不给唯一建议，不自动覆盖已有绑定 |

匹配只去除首尾空白，输出原文保持原样；大小写、全角字符、内部空格、课程名后缀和简称不改写。“大学物理”不会匹配“大学物理实验”，“高数”不会匹配“高等数学”。同名同班的重复记录也保持歧义，不能取第一条。原文没班级、仅一个课程记录时，可以给唯一候选建议，但不能将这个记录的班级当成原文已确认的事实。

资料已经关联某门课程时，也不把检索集合缩成那一门来制造唯一结果。保留原有 scope 是为了不静默改动用户/资料已有信息，不能把它当成本次匹配已确认；正式确认用例须同时处理 scope_conflict / ambiguous。
