## 范围与发现

本轮复审运行文件副本、服务启动管理、Windows 加密保存和对应测试，不代表整个产品所有业务已再次验收。

| 触发条件 | 原行为 | 修复 |
| --- | --- | --- |
| 服务已就绪后再次调用启动或重试 | 再次进入启动流程，可能覆盖原子进程记录并重复启动服务 | 已就绪直接复用；正在启动时仍复用同一个启动请求；停止后可以重新启动 |
| 加密凭据 JSON 中有非字符串条目 | 读取时静默过滤，后续保存或删除其他条目会把该记录丢掉 | 拒绝格式损坏的整份文件，操作报错且原文件保持不变 |
| 运行文件缺少 pg_isready、psql 或 createdb | 副本检查不含这些工具，可能到实际启动阶段才失败 | 完整性检查覆盖所需工具，缺失时不发布副本 |
| 完整副本的目录名被附加中文 | 内容校验通过后仍可复用中文路径 | 不复用非英文副本目录，准备新副本；原目录不删除 |
