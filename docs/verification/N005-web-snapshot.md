# N005 网页快照与发布来源

作者：金嘉睿；任务 #154；父任务 #18。依赖 N004 #144 与既有资料存储。

新增受登录和当前空间保护的 `POST /api/v1/materials/web`。联网前先检查空间及课程/学期归属，之后使用 N004 抓取组件。保存原始字节到私有存储、创建 `web` 资料与不可变原文版本，再创建待处理作业；正文提取由 N006 接入。

每次显式导入创建独立资料/版本，不自动替换已有资料。对同一网址重新导入得到新身份，旧片段仍绑定旧版本；资料版本关联和替代声明留给 N010。版本内的 `source_metadata` 保存请求网址、跳转后的网址、抓取时间、响应类型和当时提供的发布信息，之后修改资料展示元数据不会改写这些来源记录。

调用示例：

```json
{
  "url": "https://example.com/notice",
  "title": "考试安排通知",
  "publisher": "教务处",
  "published_text": "2026-11-20"
}
```

`publisher`、`published_text`、`published_at` 均可省略。发布时间未知时保持 null；只有日期时使用 `published_text`，不要补造午夜。`published_at` 若填写必须包含时区。此阶段的发布字段标记为用户提供，不自动将网页里的任意日期当作发布时间；原始页面证据始终保留。抓取时间仅记录此次实际读取完成的时间。

成功返回 material、version、job_id。网络失败返回可读错误，不保存部分正文；数据库事务失败回滚并删除已保存文件；Redis 暂时不可用仍保留快照及待投递作业，可按现有补投流程恢复。

版本列表返回来源元数据；原文下载沿用空间保护。HTML 原文以附件返回，附加 `nosniff` 与 CSP sandbox，避免同源执行上传网页中的脚本。导入 API 不跟随正文链接、不执行脚本或登录。

数据库迁移 `n005_web_snapshot_metadata` 为资料版本增加 JSONB 来源记录，旧版本默认 `{}`。先运行 `uv run --locked alembic upgrade head`。回退本迁移会移除来源记录列，应先备份需要保留的历史；文件和版本身份不由该迁移删除。

验证覆盖快照不随网站/展示元数据变化、发布时间与抓取时间分离、日期精度、未登录和跨空间请求在联网前拒绝、数据库/网络失败清理、队列失败仍保留快照、原文附件保护。命令：`pytest tests/test_web_import.py -q`，完整回归结果附 PR。
