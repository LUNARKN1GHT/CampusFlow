P95 按升序第 `ceil(0.95 × n)` 项计算，时延含查询转向量、过滤后检索、模型回答；仅统计格式合格回答，格式失败／网络失败另外保留。两种等待上限混用、样本少、未做随机交错运行，数值只是本次诊断，不能直接推断型号固有速度或正式服务指标。

四组相关片段命中均为 16/16（每轮 8 个应命中的片段，重复两轮）。但过滤后同一范围最多只有两个有效片段，返回上限为三条，命中容易获得，**此数据无法区分两个向量模型的排序质量**，不能凭相同命中数宣布两者等效。

## 已定位的问题

- 原有回答模型在正常明确问题中多次省略 `uncertainties` 字段；即使无不确定项，也没有按约定输出空列表，因此本轮记录为格式不符。
- 两种回答模型的部分原始输出把 `locator`（如 `physics-a:paragraph:1`）当作 `id`（`physics-a`）。位置与编号用途不同，当前规则要求引用必须使用提供的编号；不能自动把所有位置转换为合法引用。
- 部分缺失信息题把已知内容写在不确定性解释中，而不是事实列表，或将部分信息不足概括成整体资料不足。是否遗漏可回答要点，仍需逐条复核整份回答，不能仅统计 `claims` 字段。
- 提示词没有充分强调所有键必填、空列表写法以及 `id` 与 `locator` 的区别。该因素会影响模型比较，不能把当前差异完全归因于模型能力。

以上为代码检查及助手阅读原文所得的初步观察，**不是队友独立人工验收**，复核表的评审人与语义计数保持空白。
