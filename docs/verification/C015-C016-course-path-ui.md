# C015／C016 课程关系图与修读顺序界面

## 交付内容

- 课程路径页新增关系图：按强制先修深度分列，图例区分强制先修（实线）、并修（点划线）、建议先学（虚线），成环边与自环高亮。
- 环、矛盾、缺项、待核对候选常驻问题清单；`complete=false` 时明确标注图不完整，不隐藏问题。
- 节点与连线可点击查看课程字段、关系条件、来源候选和逐条原文证据。
- 修读顺序面板展示层次与“可替换层次”；阻塞时只列问题与具体成环路径，不渲染伪造层次。
- 下一步面板区分可进入课程与未满足条件；建议先学单独标注为不阻塞。
- 学期辅助支持学分上限、起始季节与最大学期数，展示学期、学分、警告、未排入原因、限制与假设，并固定声明不构成选课或毕业资格审核。

## 浏览器验证（真实后端／测试数据库）

- 2024 版方案：关系图 5 节点 4 边渲染；层次为 4 层并提示可替换层次；下一步显示 2 门可进入，数据库系统原理列出未满足先修；学期辅助生成秋季／春季学期，未知学分给出告警。
- 2025 修订版：图标记不完整；问题清单展示 3 节点环“分布式系统 → 云计算 → 系统可靠性 → 分布式系统”和自环“毕业设计 → 毕业设计”；顺序面板 0 层并只列阻塞原因，未伪造顺序。
- 点击节点显示课程详情；点击连线显示关系详情与条件；成环边和自环的 `.edge-cycle`／`.edge-self` 样式生效。
- `npm run build`（含 vue-tsc）通过。

## 边界

- 关系图只绘制当前方案内已确认的正式关系；候选未转换前只作为问题展示。
- 学期建议不保证能选到课，也不构成毕业资格审核。
