# N018 重复建议与合并预览界面

作者：李亦凡；任务 #174；父任务 #19。前置 N016 #169、R008 #125。

## 已实现

在 `/review/changes`「版本对照」页面新增「重复建议 / 合并预览」区域：

- 基准候选加载时读取 N015 重复建议，展示相似度、原因、命中字段和来源版本；跨范围排除项单独说明。
- 用户勾选来源候选后点击「预览合并」，调用 N016 预览，展示目标保留字段、每个来源的进度和时间块数量，以及预览令牌。
- 只有点击「确认合并预览范围」并填写原因后才发送合并请求；请求携带预览令牌，确保只合并预览过的范围。
- 「取消预览」只清空预览，原候选和重复建议保持可见；请求失败显示错误，不隐藏任何原事项。
- 合并成功后刷新对照、历史与重复建议，并显示已合并数量与“来源历史已保留”。

## 验收对照

| 验收条件 | 证据 |
| --- | --- |
| 只合并预览过的范围 | 合并请求必须带预览返回的 `token`；Playwright 断言提交体包含所选来源、原因与 `preview-token`，界面对应 N016 的 409 过期校验。 |
| 取消或请求失败不隐藏原事项 | Playwright 先取消预览，断言预览按钮消失但重复建议仍在；再模拟 500，断言错误可见且重复建议仍可见。 |

## 未覆盖与限制

- 合并范围与进度变化后需要重新预览；界面显示后端冲突提示。
- 只合并不自动选择来源；排除项只展示原因，不提供强行合并入口。
- 提醒与外部日历仍未接入，不在本界面处理。
