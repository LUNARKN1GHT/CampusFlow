## 新发现的启动问题

数据库运行程序位于中文安装路径时，首次初始化报 `invalid byte sequence for encoding
"UTF8": 0xb4`。只将运行程序换成全英文路径、保持中文数据目录不变，初始化成功。
原五项修复在全英文程序路径下端到端通过；用户已要求本轮另行修复中文安装路径。
此问题的修复和补验结果在后续更新，不以英文路径通过代替中文路径通过。
