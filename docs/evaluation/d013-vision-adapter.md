## 选型结论

1. **D014 采用智谱 glm-4v-flash 作为首个视觉识别适配器**：中文识别准确、表格可读、对模糊/缺失零编造、自述失败范围、当前零成本。
2. **适配器必须配合既有防编造规则使用**：模型输出的"原文摘录"在入库前必须能在片段文本中找到（domain 层后置校验），模型输出永远不是事实。
3. 通义千问 qwen-vl 对比评测**待补充**（未配置密钥）；接入时复用本脚本扩展第二家即可，选型结论可在数据齐备后修订。
4. 免费档存在限流风险，D014 适配器需带超时与有限重试，失败样本进入"可重试"状态（与 J 系列队列策略一致）。
