## 选型结论与限制

1. **本阶段仅完成单模型基线**：智谱 glm-4v-flash 在合成样本上满足协议所需的识别与失败报告能力，作为 D014 的首个视觉识别适配器实现。
2. **这不是最终选型**：通义千问 qwen-vl 对比评测尚未进行（未配置密钥）；待补齐后如结论变化，将修订本文档与适配器配置。
3. **适配器必须配合既有防编造规则使用**：模型输出的"原文摘录"入库前必须能在片段文本中找到（domain 层后置校验），模型输出永远不是事实。
4. 免费档存在限流风险，D014 适配器需带超时与有限重试，失败样本进入"可重试"状态（与 J 系列队列策略一致）。
