# 课程项目 PRE

## 0. 事先约定

### 0.1 PRE 核心内容

项目核心思想：**一份课程资料，如何变成一条有原文依据、经过比对、可以执行的学习安排**。

全场展示最好只用一个贯穿案例，集中于一个使用场景。系统中的一些分支内容放在一面列出来即可，不需要过多说明。

### 0.2 PRE 分工

1. **李亦凡**：介绍项目架构，系统整体是如何搭建的，各个模块如何设计；
2. **金嘉睿**：业务数据模型、核对状态机与正式事项转换；
3. **吴思彤**：数据处理方式，如何接入资料，如何定位并解析资料中的各部分内容；
4. **顾昕越**：数据来源说明，（如果可用）项目使用场景，以及项目现在的使用边界，未来可能的扩展。

20 分钟的介绍时间，人均五分钟，最后组长来收尾。PPT 暂时不知道怎么做，但务必提前把稿子写出来。
