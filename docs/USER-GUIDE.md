# CampusFlow 用户使用手册

本手册面向使用 CampusFlow 管理学期、课程、资料、任务、学习计划与提醒的学生用户。

- 手册对应的界面：当前仓库 `develop` 分支（2026-11-15）。
- 桌面安装包下载、签名状态、升级与卸载的细节，见 [桌面版使用指南](desktop/user-guide.md)。
- 本地开发环境的启动命令，见 [开发文档](DEVELOPMENT.md)。

> 本手册只描述界面中实际存在的入口。智能问答、待核对、版本对照与外部日历的前端页面自 2026-11-12 起暂不提供入口，相关后端能力保留；本手册会明确说明这些功能当前不能在界面中操作，避免按已下线入口寻找功能。

## 1. 当前可用功能

登录后，顶部导航提供以下 8 个页面：

| 页面 | 地址 | 主要用途 |
| --- | --- | --- |
| 总览 | `/` | 查看今天的时间块、近期截止任务、未完整排入与冲突风险 |
| 课程 | `/courses` | 新建学期与课程、归档学期 |
| 资料库 | `/library` | 导入 PDF、图片、DOCX、粘贴文本与公开网页，查看处理状态和原文定位 |
| 任务 | `/tasks` | 管理任务、进度、依赖、子任务与固定日程 |
| 学习计划 | `/plan` | 生成两周／自定义区间计划草案，接受、调整与局部重排 |
| 提醒 | `/reminders` | 查看提醒、设置默认规则与单个任务规则 |
| 导出 | `/export` | 导出所选任务清单 CSV 或已接受计划的 ICS 日历草案 |
| 设置 | `/settings` | 时区、学习容量、每周可用时间、AI 服务、主题色系与工具箱 |

另有三个不在主导航中的页面：

| 页面 | 入口 | 说明 |
| --- | --- | --- |
| 工具箱 | 设置页 → 工具箱 → 进入工具箱 | 课程路径等低频功能的集中入口 |
| 课程路径 | 工具箱 → 进入课程路径，或直接访问 `/course-paths` | 培养方案、课程关系、关系图、修读顺序与学期试排 |
| 系统状态 | 登录后直接访问 `/health` | 只检查 API 进程是否可达，仅供开发与诊断 |

### 当前暂不提供前端入口的功能

以下页面自 2026-11-12 起暂不提供前端入口，后端接口仍然保留：

- 智能问答
- 待核对
- 版本对照
- 外部日历

对日常使用的影响：

1. 资料识别可以生成候选事项，但候选仍是“待核对”，当前界面不能逐字段修正、确认或转成正式任务。需要执行的任务请在「任务」页手动创建。
2. 资料库中的「问答索引」状态只表示检索数据是否准备好，当前不能打开问答对话。
3. 需要把计划放进日历时，请使用「导出」生成 ICS 日历草案，再自行导入日历；应用不会直接写入外部日历。
4. 版本对照、变更接受与外部日历的逐项确认目前不在界面操作范围内。

## 2. 基本概念

理解下面几组区别，可以避免大多数误操作。

| 概念 | 含义 |
| --- | --- |
| 学期 | 一段有开始与结束日期的学习周期；归档只切换标记，不删除数据 |
| 课程 | 属于某个学期的课程，可填写课程代码、教学班与教师 |
| 资料与来源版本 | 一份导入的课程通知、教学大纲、网页或截图；同一份资料可以有多个版本 |
| 原文读取 | 资料正文是否已经解析并保存，可查看原文定位 |
| 问答索引 | 检索所需的数据是否已经准备好；与原文读取是两件事 |
| 候选事项 | 从资料中提取出的待核对建议，不是正式任务 |
| 固定日程 | 不可移动的上课、实验等时间区间，支持每周重复 |
| 可用时间 | 每周可以用于学习的时段，供计划生成使用，不是固定日程 |
| 正式 DDL | 任务真正的截止日期，来自用户补充、原文规定或系统推断 |
| 个人目标 | 用户希望自己完成任务的日期，不改变正式 DDL |
| 计划草案 | 生成后尚未接受的安排，不影响当前计划 |
| 当前计划 | 用户接受后的计划；只有它能被导出和用于总览 |
| 时间块 | 当前计划中安排给某个任务的一段学习时间 |
| 提醒规则 | 控制提前量、重复、暂停与启用的规则；只生成提醒，不改变任务 |

需要特别注意：

- 移动计划中的时间块不会改写任务的正式 DDL。
- 只有日期的截止不会被补造成某个具体时刻；界面会标明“仅日期”。
- 计划草案不是当前计划；必须点击「接受为当前计划」后才生效。
- 删除资料后，引用不再可验证；不要把已删除来源的引用继续当作依据。
- 候选事项在被确认前不会成为正式任务，也不会自动参与排期。

## 3. 安装、启动与登录

### 3.1 桌面版

桌面版支持 macOS（arm64／x64）与 Windows（x64），自带 Python 运行时、PostgreSQL 17 与 pgvector，不需要另装 Docker、Python、Node、PostgreSQL 或 Redis。

首次启动会自动初始化内置数据库并启动 API 与后台 Worker，随后自动登录本机单用户会话。初始化期间会显示当前阶段；失败时会显示阶段、退出码与日志目录。

用户数据目录：

| 平台 | 位置 |
| --- | --- |
| macOS | `~/Library/Application Support/CampusFlow/data` |
| Windows | `%APPDATA%\CampusFlow\data` |

目录中包含 `pgdata`（数据库）、`materials`（资料原文）、`logs`、`backups`、`run` 与 `secrets.json`（仅在不支持系统凭据后端时使用）。不要手动修改或删除这些目录；迁移与备份请使用菜单中的「数据」入口。

安装包核对、Gatekeeper／SmartScreen 处理、升级与卸载步骤见 [桌面版使用指南](desktop/user-guide.md)。

### 3.2 本地开发版

本地开发版需要 PostgreSQL、Redis、Python 3.12、uv 与 Node.js。完整步骤见 [开发文档](DEVELOPMENT.md)，最短流程如下：

```bash
# 终端 1：启动 PostgreSQL 与 Redis（在 infra/ 目录）
docker compose up -d

# 终端 2：后端
cd backend
uv sync --locked
uv run --locked alembic upgrade head
uv run --locked uvicorn campusflow.main:app --reload --host 127.0.0.1 --port 8000

# 终端 3：前端
cd frontend
npm ci
npm run dev
```

浏览器访问 <http://127.0.0.1:5173>。

本地开发默认账号：

- 用户名：`student`
- 密码：`campusflow-dev`

默认凭据只用于本机单用户开发。复制 `backend/.env.example` 为 `backend/.env` 后，可用 `CAMPUSFLOW_LOCAL_USERNAME` 与 `CAMPUSFLOW_LOCAL_PASSWORD` 覆盖；共享部署前必须替换默认凭据，并使用生产级会话存储。

### 3.3 登录与会话

登录页包含用户名与密码两个字段，用户名为 `student` 时默认已填入，密码需要手动输入。

- 登录成功后会回到原目标页面；直接访问登录页且已登录时会回到总览。
- 会话保存在 HttpOnly Cookie 中，默认有效期 12 小时；后端重启后会话失效，需要重新登录。
- 会话失效时页面会提示“会话已失效，请重新登录”，重新登录后回到之前的页面。
- 顶栏右侧的「退出」会作废当前浏览器的会话并回到登录页。
- 桌面版由应用自动登录本机账号；如果自动登录失败，登录页顶部会提示“自动登录未完成，请使用本机账号 … 登录”。

常见登录错误：

| 提示 | 含义与处理 |
| --- | --- |
| 用户名或密码错误。 | 检查账号密码；本地开发默认账号见上一节 |
| 无法连接服务，请检查网络或确认后端已经启动。 | 后端未启动或地址不可达 |
| 请求超时，请检查网络后重试。 | 网络或服务响应超时 |
| 服务暂时不可用，请稍后重试。 | 服务端异常 |

### 3.4 顶部导航与显示

顶部导航从左到右为：总览、课程、资料库、任务、学习计划、提醒、导出、设置。

顶栏右侧提供：

- 浅色／深色／跟随系统切换；
- 当前用户名；
- 退出。

主题色系（绿色／蓝色／白色）在「设置 → 显示」中切换。深浅模式与色系彼此独立，选择只保存在本机浏览器，不写入工作空间设置。

## 4. 快速开始

第一次使用时，建议按下面的顺序完成配置。整套流程大约 10 分钟。

| 步骤 | 页面 | 操作 | 完成标志 |
| --- | --- | --- | --- |
| 1 | 设置 | 确认时区、每日／每周容量与休息、提交缓冲 | 点击「保存设置」后出现保存成功提示 |
| 2 | 设置 | 添加每周可用时段 | 列表中出现至少一个可用时段 |
| 3 | 课程 | 新建学期，再添加课程 | 学期卡片下出现课程 |
| 4 | 任务 | 添加任务，填写标题、DDL、优先级与预计耗时；需要时添加固定日程 | 任务出现在任务列表，固定日程出现在周视图 |
| 5 | 资料库 | 导入课程资料；粘贴文本可点击「开始识别」 | 原文读取与问答索引状态可见 |
| 6 | 学习计划 | 选择区间，点击「生成草案」，阅读预览后点击「接受为当前计划」 | 页面显示当前计划与版本号 |
| 7 | 提醒、导出 | 按需调整提醒规则；需要时预览并下载 CSV／ICS | 提醒列表可见，导出文件下载到本机 |
| 8 | 总览 | 每天查看今日安排与近期截止，回到任务页更新进度 | 总览与任务进度保持一致 |

最小可排期条件：

1. 至少有一个每周可用时段；
2. 至少有一个未完成、带预计耗时的任务；
3. 任务的截止与依赖不会阻止排入。

如果只想管理任务，可以只完成步骤 3 和 4；资料、计划和提醒都是可选能力。

## 5. 界面导览

### 5.1 页面切换

- 主导航只显示 8 个常用页面；当前页面会高亮。
- 课程路径不在主导航中，从「设置 → 工具箱 → 进入工具箱 → 进入课程路径」进入。
- 直接访问已下线路径（例如 `/qa`、`/review`、`/calendar`）不会报错，但会回到总览，并在页面顶部提示“页面不存在：该地址可能已经下线”。

### 5.2 页面内反馈

- 表单错误会显示在表单附近，已填写内容会保留。
- 长列表的加载失败会显示「加载失败」和「重新加载」。
- 操作结果分为成功提示、错误提示与行级提示；行级错误只影响当前条目。
- 资料库状态会自动刷新；离开页面或页面不可见时会暂停轮询，超过 10 分钟后自动刷新会暂停，需要点击「刷新」查看最新状态。

### 5.3 时间显示

- 业务时间按工作空间时区解释；设置页可以修改时区。
- 任务截止、固定日程、可用时间、计划区间与导出都使用工作空间时区。
- 只有日期的截止显示为日期，不会补出 00:00 或 23:59。
- 夏令时缺失或重复的时刻会明确报错，不会静默换算。

## 6. 设置

设置页顶部说明：“这些偏好决定后续排期可使用的时间与缓冲，但不会修改课程 DDL。”

### 6.1 时间基准与学习容量

| 字段 | 范围 | 默认值 | 作用 |
| --- | --- | --- | --- |
| 时区 | IANA 时区名称 | `Asia/Shanghai` | 解释固定日程、计划区间、截止时间与导出时间 |
| 每日可学习容量（分钟） | 0–1440 | 240 | 每天最多安排的学习分钟数 |
| 每周可学习容量（分钟） | 0–10080 | 1680 | 每周最多安排的学习分钟数 |
| 每段休息（分钟） | 0–240 | 15 | 时间块之间的休息 |
| 提交缓冲（分钟） | 0–1440 | 30 | 在截止前预留的缓冲时间 |

操作步骤：

1. 修改需要的字段；时区可以直接输入，也可以从候选列表中选择。
2. 点击「保存设置」。
3. 看到“学习偏好已保存”后，设置即生效。

注意：

- 每日容量与每周容量独立保存，不会自动改动可用时段，也不会自动改写课程 DDL。
- 修改时区后，服务端会按新时区重算提醒窗口；已保存的固定日程、任务 DDL 与既有计划不会被改写。
- 新设置主要影响后续生成或重排的计划。

### 6.2 每周可用时间

可用时间表示“每周哪些时段可以用于学习”，会参与计划生成。

添加时段：

1. 在「添加可用时段」面板选择星期（周一至周日）。
2. 填写开始与结束时间，例如 19:00–21:00。
3. 点击「添加时段」。

规则：

- 结束时间必须晚于开始时间。
- 不支持跨日时段；例如 23:00–01:00 需要拆成两条。
- 重叠时段会被拒绝。
- 删除时段前会弹窗确认；删除后该时段不再参与后续排期，已生成计划中的时间块不会被改写。
- 没有任何可用时段时，计划无法自动安排学习块，页面会明确提示。

### 6.3 AI 服务

「设置 → AI 服务」用于配置模型密钥。模型能力与密钥的对应关系：

| 能力 | 使用的密钥 | 说明 |
| --- | --- | --- |
| 文字生成 | ZHIPU 或 DeepSeek | 文字供应方可选「智谱 GLM（ZHIPU）」或「DeepSeek」 |
| 图片识别 | ZHIPU | 截图与图片识别 |
| 向量检索 | ZHIPU | 资料索引与检索 |

操作步骤：

1. 选择文字供应方。
2. 填写对应的 API 密钥；已保存的密钥不会回显，留空表示不修改。
3. 如确需删除密钥，勾选「清除已保存的 … 密钥」，不要同时填写新密钥和清除同一密钥。
4. 点击「保存 AI 配置」。

保存后的行为：

- 文字生成与检索能力立即使用新密钥；问答页面当前没有入口，索引数据仍会准备。
- 后台资料处理（解析后的索引与识别）需要重启应用后使用新密钥；页面会提示“需要重启应用”。
- 未配置密钥时应用仍可启动，本地资料、任务、计划、提醒与导出可用；识别与索引相关操作会以明确原因失败，不会伪造结果。
- 密钥保存在本机凭据存储（macOS 钥匙串、Windows DPAPI，或数据目录内权限 0600 的凭据文件），页面和接口只显示“已配置／未配置”，导出归档不包含密钥。
- 如果服务端由环境变量配置密钥，页面会显示「由环境变量配置」，此时不能在应用内修改。

### 6.4 显示与主题色系

- 深浅模式：顶栏右侧切换浅色／深色／跟随系统。
- 主题色系：设置页选择绿色、蓝色或白色。
- 两者独立叠加，立即生效，只保存在本机浏览器，不写入工作空间设置。

### 6.5 工具箱

设置页的「低频功能 / 工具箱」提供「进入工具箱」链接。工具箱目前只有一项：

- 课程路径：培养方案、课程关系与学期试排。

工具箱只改变入口位置，不改变已保存的培养方案、课程关系或计划。

### 6.6 系统状态

`/health` 页面（登录后访问）只检查本机 API 进程是否可达，不代表数据库、模型配置或业务数据已就绪。该页面不在主导航中，仅供开发与诊断使用。

## 7. 学期与课程

### 7.1 学期

在「课程」页可以新建学期。表单字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 学期名称 | 是 | 最多 100 字，例如“2026 秋季学期” |
| 开始日期 | 是 | 日期选择器 |
| 结束日期 | 是 | 日期选择器，不能早于开始日期 |

操作：

1. 点击「添加学期」。
2. 填写名称与起止日期。
3. 点击「保存学期」。

学期卡片提供「归档」与「恢复」：

- 归档只切换标记，不删除关联课程、任务、进度、固定日程或计划。
- 归档后默认从列表中隐藏；勾选「显示历史学期」可以查看。
- 恢复后重新显示并恢复常规使用。

### 7.2 课程

在学期卡片下点击「添加课程」。表单字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 课程名称 | 是 | 最多 200 字 |
| 课程代码 | 否 | 最多 50 字，例如 CS301 |
| 教学班 | 否 | 最多 100 字，例如 1 班 |
| 教师 | 否 | 最多 100 字 |

操作：

1. 选择目标学期。
2. 点击「添加课程」。
3. 填写课程信息并点击「保存课程」。

说明：

- 同名课程通过课程代码和教学班区分；留空的可选字段会明确保存为空。
- 课程可以编辑，当前界面不提供删除课程的入口。
- 归档学期时，课程不会被删除，只是随学期一起隐藏。

## 8. 资料库

资料库用于保存课程通知、教学大纲、作业要求与群聊截图，并记录原文位置。

### 8.1 三种导入方式

点击页面上方的「导入资料」，选择「粘贴文本」「上传文件」或「公开网页」。

| 方式 | 适用内容 | 是否自动解析 | 是否自动建立索引 |
| --- | --- | --- | --- |
| 粘贴文本 | 从聊天、网页或文档复制的文字 | 保存时切分段落 | 不自动；需要在资料行点击「开始识别」 |
| 上传文件 | PDF、DOCX、PNG、JPG／JPEG | 上传后进入后台解析 | 解析完成后自动准备问答索引 |
| 公开网页 | 公开可访问的网页 | 抓取快照后解析正文 | 解析完成后自动准备问答索引 |

### 8.2 粘贴文本

字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 标题 | 是 | 最多 300 字 |
| 正文 | 是 | 粘贴的原文 |
| 发布方 | 否 | 通知或文件的发布方 |
| 学期 | 否 | 未指定时不属于具体学期 |
| 课程 | 否 | 未关联课程 |
| 教学班 | 否 | 可留空 |
| 发布时间 | 否 | 需要完整时间与时区，例如 `2026-10-13T10:30:00+08:00` |

点击「导入文本」后，系统只保存原文并切分段落。**保存原文不会自动调用模型，也不会自动提取事项。**

导入成功后，资料行会出现「原文保存与识别分开」区域。需要索引或提取任务候选时：

1. 找到该条资料；
2. 点击「开始识别」；
3. 等待按钮从「正在识别…」恢复；
4. 查看该行的问答索引状态与事项提取结果。

识别会准备问答索引并提取任务类候选事项。候选仍需人工核对，确认前不会成为正式任务；由于待核对页面当前没有入口，识别结果只能用于查看状态，不能在本界面完成确认或转换。

### 8.3 上传文件

支持格式：

- PDF
- Word（DOCX）
- PNG
- JPG／JPEG

旧版 DOC、DOCM 等格式不支持，请先另存为普通 `.docx` 再上传。

限制：

- 单文件默认不超过 20 MB；
- 一次默认最多 5 个文件；
- 文件扩展名与真实内容必须一致，伪造扩展名会被拒绝；
- 上传可能需要较长时间，页面会显示处理进度。

可选字段与选项：

- 学期、课程、教学班；
- 「允许重复导入相同文件」。

默认情况下，完全相同的文件会提示复用已有资料，不会重复建档；勾选「允许重复导入相同文件」后才会重复导入。

选择文件与可选范围后，点击「上传并处理」。批量上传会逐项返回结果，并汇总“成功 N 份，重复 N 份，失败 N 份”。失败文件不会建档，也不影响同批次其它文件。

如果上传超时，页面会提示“结果未知”，请先点击「刷新」确认文件是否已经建档，不要直接重复上传相同文件。

### 8.4 公开网页

字段：

- 网页网址（必填，最多 500 字）；
- 标题（必填）；
- 学期、课程、教学班（可选）；
- 发布方、发布时间、发布日期原文（可选）。

点击「读取网页并处理」后，系统会保存网页快照并创建解析作业。

注意：

- 只读取公开页面，不会自动登录教务系统、提交表单或绕过登录／反爬验证；
- 如果网页需要登录、出现登录表单或抓取失败，页面会给出原因，并提供「改为粘贴原文」「改为上传文件」的替代入口；
- 抓取时间不等于发布时间，发布时间需要按页面原文填写。

### 8.5 处理状态

每份资料显示两条独立的状态轴：

| 状态轴 | 可能状态 | 含义 |
| --- | --- | --- |
| 原文读取 | 原文待读取、原文读取中、原文已读取、原文部分读取、原文读取失败 | 正文是否已解析、是否可查看原文 |
| 问答索引 | 问答索引未开始、准备中、已准备、部分准备、失败、待核对 | 检索数据是否已准备好 |

- 原文读取完成不等于问答索引已准备好。
- 部分成功会显示「部分成功 · 未覆盖范围」，列出缺失范围与失败原因。
- 缺失内容不会被当作“没有要求”；重试只补齐未识别的范围。
- 索引失败时可以直接看到失败原因；可重试时会出现「重试索引」。
- 文件处理失败且可重试时会出现「重试处理」；不可重试时会明确标注。

列表支持按学期、课程、来源、原文状态筛选，并可勾选「包含已归档」。

### 8.6 查看原文与引用定位

点击资料行的「查看原文」打开「原文定位」面板：

- 左侧是来源片段列表，定位形式包括第 N 段、第 N 页或截图区域；
- 右侧显示原文并高亮对应片段；PDF 会定位到对应页，图片会显示截图区域；
- 面板同时显示引用标识、来源类型、位置、适用范围、识别置信度与是否可验证。

说明：

- DOCX 与网页当前只支持片段与定位信息，不支持在面板中直接渲染原文件；
- 原文文件不可读取时，页面会提示“原文件暂不可读取，引用目前无法验证”；
- 已归档资料会提示来源已归档；
- 判断引用是否可验证，要看能否在原文中定位到对应片段，而不是只看引用编号是否存在。

### 8.7 归档与删除

点击「归档 / 删除」打开「归档与删除」面板。

归档：

- 点击「归档资料」后，资料退出检索与问答，引用保留并标注为已归档；
- 点击「恢复已归档资料」后，引用重新生效；
- 归档不会删除片段或正式任务。

删除：

1. 点击「预览删除影响」；
2. 查看将删除的版本数、失效片段数、受影响任务数与候选事项数；
3. 选择关联任务的处理方式：
   - 「保留任务，标注来源已删除（推荐）」；
   - 「随资料一并删除」；
4. 点击「确认删除以上范围」。

注意：

- 删除必须先生成预览；预览后如果范围发生变化，需要重新预览；
- 删除完成后，原文件、派生内容与按选择删除的关联任务会被移除；
- 保留下来的任务仍可查看，但来源会标注为已删除，相关引用不再可验证；
- 删除面板会显示备份保留说明；删除失败时资料仍可访问，可以重新预览后再试。

### 8.8 资料库当前限制

- 候选事项不能在当前界面确认、忽略或转成正式任务；
- 问答界面没有入口，索引状态只说明检索数据是否准备好；
- DOCX 与网页不能直接渲染原文件，只能查看片段与定位；
- 粘贴文本不会自动提取，必须点击「开始识别」；
- 文件资料解析完成后会自动准备问答索引，但不会自动提取任务候选；
- 部分解析失败必须显示未覆盖范围，不能据此断言“没有要求”。

## 9. 任务与固定日程

### 9.1 添加任务

在「任务」页点击「添加任务」。表单字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 任务标题 | 是 | 最多 300 字 |
| 关联课程 | 否 | 不关联课程时仍可管理任务 |
| 说明 | 否 | 任务说明 |
| 正式 DDL 日期 | 否 | 日期选择器 |
| DDL 时刻 | 否 | 只有填写了日期才能填写时刻 |
| 优先级 | 否 | 低、中、高 |
| 个人目标日期 | 否 | 只作为个人目标，不改变正式 DDL |
| 截止来源 | 否 | 用户补充、原文规定、系统推断 |
| 截止来源说明 | 否 | 最多 500 字 |
| 原始预计分钟 | 否 | 最小 1 分钟 |
| 当前剩余分钟 | 否 | 最小 0 分钟 |

填写后点击「保存任务」。

说明：

- 只有日期、没有时刻的截止会保持“仅日期”精度，不会补造具体时刻；
- 个人目标日期与正式 DDL 分开展示，个人目标不会改变正式 DDL；
- 任务可以编辑；编辑后如果不在当前筛选结果中，页面会提示调整筛选。

### 9.2 进度与调整历史

任务支持五种进度：

- 未开始
- 进行中
- 受阻
- 已完成
- 已取消

点击任务行的「进度」可以更新状态并填写调整原因（最多 500 字）。

规则：

- 完成或取消会将剩余耗时记为 0；
- 重新打开时按原始估计恢复剩余耗时；
- 历史记录不会删除；
- 调整历史显示旧状态 → 新状态、时间、原因与剩余耗时变化；
- 状态没有变化时，「更新进度」按钮不可用。

逾期由截止时间与完成情况计算，显示为「已逾期」；逾期不替代进度状态。

### 9.3 依赖

点击任务行的「依赖与子任务」管理依赖：

- 「前置任务」列出当前任务依赖的任务，可点击「删除依赖」；
- 在「前置任务编号」输入任务编号，点击「添加依赖」；
- 「后续任务」列出依赖当前任务的任务；
- 不支持自依赖；新增依赖会检测全空间成环，成环时返回具体路径并拒绝保存。

任务页下方的依赖检查面板会显示：

- 「可执行」或「存在阻塞」；
- 未发现成环、范围外前置或已取消前置时的说明；
- 阻塞任务列表。

依赖会影响排期：前置任务未完成、被取消、越出范围或无法排入时，后续任务会被列为未排入并给出原因。

### 9.4 子任务与拆分建议

在「子任务」区域可以：

- 点击「生成拆分建议」，由系统给出只读的拆分建议；
- 点击「手动添加一行」，逐行填写子任务标题与剩余分钟；
- 点击「按以上内容创建子任务」。

规则：

- 子任务属于父任务，但不会复制父任务的来源；
- 仅支持一层子任务；
- 有子任务的父任务只作为汇总容器，排期只安排子任务，避免重复计入耗时；
- 父任务卡片显示子任务数量、预计／剩余耗时与完成度；
- 拆分建议来自任务内容，如果建议已过期或属于其他任务，需要重新生成后再创建。

### 9.5 筛选与定位

任务页支持按学期、课程、进度筛选，并显示当前结果数量。

- 选择学期时，未关联课程的任务可能不在筛选结果中；
- 任务列表支持从总览通过链接定位：总览中的任务链接会打开任务页并高亮对应任务；
- 保存任务后如果它不在当前筛选结果中，页面会提示调整筛选，不会让任务“消失”。

### 9.6 固定日程

固定日程显示在任务页底部，按周一到周日展示。

点击「添加日程」填写：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 标题 | 是 | 最多 300 字 |
| 关联课程 | 否 | 可选 |
| 开始时间 | 是 | 日期与时刻 |
| 结束时间 | 是 | 日期与时刻 |
| 地点 | 否 | 最多 200 字 |
| 重复 | 否 | 不重复或每周重复 |
| 重复截止日 | 每周重复时必填 | 重复结束日期 |

填写后点击「保存日程」。

保存后：

- 固定日程按周视图展示，跨日边界显示为 00:00／24:00；
- 时间按工作空间时区解释；
- 夏令时缺失或重复时刻会明确报错；
- 时间重叠由服务端校验，错误会显示在表单中；
- 每周重复的日程会展开为每周实例；
- 删除固定日程前会确认，并说明每周重复实例也会一并移除。

固定日程与可用时间的区别：

- 固定日程是“不可移动”的时间区间，例如上课、实验；
- 可用时间是“可以用于学习”的每周时段；
- 两者都会影响计划，但固定日程不会被计划移动。

### 9.7 与计划的关系

- 计划先满足固定日程、明确截止时间与必要依赖，再考虑优先级、学习容量与休息；
- 移动学习时间块不会改变任务的正式 DDL；
- 锁定时间块在局部重排时会保留；
- 完成任务或修改截止后，提醒会按规则重算。

## 10. 学习计划

### 10.1 生成前的准备

生成计划前，建议确认：

1. 已在设置中添加每周可用时段；
2. 任务已填写预计耗时；
3. 重要任务已填写正式 DDL 与优先级；
4. 固定日程与依赖关系已经录入。

没有可用时间或没有带耗时的任务时，计划无法自动生成时间块。

### 10.2 区间与假设

「学习计划」页的区间选项：

| 区间 | 说明 |
| --- | --- |
| 今天 | 只安排今天 |
| 本周 | 周一至周日，可跨月 |
| 未来两周 | 从今天起含今天与第 14 天（默认） |
| 自定义 | 必须同时选择开始与结束日期；含首尾最多 366 天 |

所有区间边界按工作空间时区解释。

「可选假设」用于补充缺失信息，留空表示不假设：

| 假设 | 说明 |
| --- | --- |
| 缺失耗时按（分钟） | 为没有预计耗时的任务假设一个时长 |
| 单段最长（分钟） | 单个时间块的最长分钟数，例如 90 |
| 提交缓冲（分钟） | 为截止预留的缓冲；留空时按设置中的缓冲 |

每日／每周容量与休息间隔不在这里设置，请在「设置」中修改。

### 10.3 生成草案

点击「生成草案」后，页面会显示「生成中…」，完成后出现待接受的计划草案。

- 生成草案不会改变当前计划；
- 新的草案会替换当前预览，但不会自动接受；
- 如果已有当前计划，可以点击「查看当前计划」切回。

### 10.4 阅读预览

预览摘要包括：

- 状态：待接受草案／当前计划／已被替代；
- 版本号、范围、时区；
- 容量缺口；
- 任务统计：完整排入、部分排入、未排入、不参与。

「冲突与风险」面板会分别显示确定冲突与风险，例如：

- 时间重叠；
- 截止风险；
- 学习负荷风险。

每条会标明是「确定冲突」还是「风险」，以及是否「基于耗时估计」，并给出建议。

「时间块」按日期分组，显示时段、任务标题、分钟数、理由与约束标签，并标注：

- 保留安排；
- 新安排／移动；
- 已锁定。

「未完整排入的任务」会列出未排入原因、缺口分钟数与调整选项。「待补充项」和「本次使用的假设」分别显示缺失信息与本次使用的假设。

「检查覆盖与限制」显示未执行的检查、限制说明与生成／接受时间。

### 10.5 接受为当前计划

只有待接受草案会显示「接受为当前计划」。

1. 核对预览中的时间块、冲突与未排入任务；
2. 点击「接受为当前计划」；
3. 看到“已接受 vN”后，当前计划生效。

说明：

- 接受后当前计划与刚才预览的草案一致；
- 如果草案在提交前发生变化，页面会提示“草案已更新，请重新确认”；
- 接受计划不会修改任务 DDL；
- 只有当前计划可以用于导出和总览。

### 10.6 调整时间与锁定

只有当前计划的时间块可以调整：

- 点击「锁定」后，该块在局部重排时保留；
- 点击「解锁」恢复可调整；
- 点击「调整时间」填写新的开始与结束时间，点击「保存」；
- 点击「取消」放弃本次修改。

调整时间块不会改写任务原始 DDL；未接受前不会影响现有安排。

### 10.7 保留锁定块重排

已有当前计划时，可以点击「保留锁定块重排」：

- 基于当前已接受计划生成新的待接受草案；
- 锁定块与指定范围外的现有块原样保留；
- 范围内未锁定任务重新分配；
- 重排结果仍需点击「接受为当前计划」后才生效。

### 10.8 调整建议

「需要调整吗？」面板会比较当前输入与已接受计划，列出任务、可用时间、容量、固定日程、依赖等变化建议。

- 面板只给建议，不会自动修改当前计划；
- 受影响任务会列出任务名、编号或“未定位”；
- 点击「生成本地调整草案」后生成待接受草案；
- 点击「重新检查」重新读取变化；
- 接受草案前，当前计划保持不变；
- 接受后也不会改变任务 DDL。

### 10.9 常见状态

| 情况 | 页面提示与处理 |
| --- | --- |
| 没有可用时间 | 检查设置中的每周可用时间 |
| 任务没有耗时 | 为任务填写预计耗时，或在假设中填写缺失耗时 |
| 容量不足 | 查看容量缺口与“未完整排入的任务”，调整容量、区间或任务 |
| 冲突 | 查看冲突类型与建议，调整时间块或任务 |
| 草案已更新 | 重新阅读并确认后再接受 |
| 当前计划已被替代 | 查看最新草案并重新接受 |

## 11. 提醒

### 11.1 工作方式

- 提醒在打开提醒页或发生相关操作时同步计算，不是后台定时推送；关闭应用期间不会发送系统通知。
- 提醒只生成待发送、已发送、已忽略或已撤销记录，不修改任务截止、核对状态或计划。
- 页面明确提示：“没有提醒不代表没有待办或冲突。”

会触发提醒重算的操作包括：

- 更新任务进度；
- 修改任务截止；
- 接受计划；
- 修改提醒规则；
- 修改工作空间时区。

### 11.2 提醒列表

页面顶部显示未读、待发送、已发送、已忽略、已撤销的汇总数量，并提供「全部」「未读」「已读」筛选。

每条提醒显示：

- 任务标题；工作空间级提醒显示为「工作空间提醒」；
- 状态：待发送、已发送、已忽略、已撤销；
- 未读／已读；
- 类型：截止提醒／待核对提醒；
- 提醒内容；
- 计划提醒时间；
- 任务入口。

可以执行：

- 「标为已读」：仅已发送且未读的提醒；
- 「忽略」：待发送或已发送的提醒。

### 11.3 默认规则

「所有任务的提醒规则」是默认规则，适用于没有单独规则的任务。

字段：

| 字段 | 默认值 | 范围／说明 |
| --- | --- | --- |
| 默认提前量（分钟） | 1440 | 0–10080，必填 |
| 默认重复间隔（分钟，可留空） | 空 | 1–10080；留空表示不重复 |
| 暂停默认提醒 | 未勾选 | 勾选后保留规则但不生成提醒 |
| 启用默认规则 | 已启用 | 停用后不再生成提醒 |

操作：

- 「保存默认规则」：保存后，新的待发送提醒会按当前规则重新生成；
- 「重置」：恢复默认值；
- 只有日期的截止不会补造具体时刻，提醒正文会标明“截止仅有日期，不表示具体时刻”。

### 11.4 任务单独规则

在「任务单独规则」区域可以为单个任务创建规则：

1. 选择任务；
2. 填写任务提前量与重复间隔；
3. 选择是否暂停或启用；
4. 点击「创建任务规则」。

已有规则可以「编辑」「暂停」「恢复」「删除」：

- 单独规则优先于默认规则；
- 删除单独规则后，任务回退使用默认规则；
- 新规则会继承默认提前量，但不继承默认重复间隔；
- 已完成或已取消的任务不再生成提醒。

### 11.5 特殊情形

- 仅有日期的截止：不会补造时刻，提醒会按日期窗口生成；
- 来源失效：确定截止提醒会撤销，改为待核对的 `review` 提醒；
- 存在待核对候选：生成带数量的工作空间级提醒，确认后不再新增；
- 暂停规则：保留规则但不生成提醒；
- 停用规则：不再生成提醒；
- 恢复规则：后续提醒重新生成，已读或已忽略的历史不会重新激活。

## 12. 导出

导出用于把任务清单或已接受计划带到本机文件，不会写入外部日历、发送消息或自动同步。

### 12.1 选择范围

支持两种范围：

1. 「所选任务」：逐项勾选任务；搜索只用于查找，不会把搜索结果自动加入导出范围；
2. 「已接受计划」：从下拉列表选择一份已接受的计划；草案不能导出。

限制：

- 系统不提供整空间导出；
- 一次最多导出 500 个任务；
- 没有勾选任务时不能预览；
- 没有已接受计划时，页面会提示先到学习计划接受草案。

### 12.2 选择格式

| 格式 | 适用范围 | 说明 |
| --- | --- | --- |
| CSV 任务清单 | 所选任务 | UTF-8 带 BOM，便于表格软件打开中文 |
| ICS 日历草案 | 所选任务或已接受计划 | 用于导入日历的草案文件 |

计划模式当前只提供 ICS，计划清单 CSV 尚未提供；切换到计划模式时会自动改为 ICS。

### 12.3 选项

- 「包含来源提示（只含资料标题、版本号和定位，不含原文摘录）」：默认关闭；只有来源仍可核对时才会写入；
- 「同时导出固定日程（仅计划模式的 ICS）」：默认关闭；勾选后会把固定日程展开写入 ICS。

### 12.4 预览与范围指纹

必须先点击「预览」，确认预览内容后才能下载。

预览包括：

- 源对象、日历事件数／清单行数；
- 日期范围与时区；
- 条目不完整时的说明；
- 仅日期截止、带时刻截止、没有截止、已排入、未排入、来源失效、已取消的计数；
- 排除项与警告；
- 逐条预览内容，包括是否排除、来源是否失效、排除原因与来源提示。

预览会生成一个范围指纹：

- 范围、格式、计划、选项或勾选发生变化后，旧预览立即失效，需要重新预览；
- 下载会携带该指纹；
- 指纹不一致时服务端返回 409，页面会清空预览并提示“范围已变化，请重新预览”。

### 12.5 下载

- 点击「下载」后，文件保存到本机；
- 下载完成会提示“文件只保存到本机，服务端不保留导出文件”；
- 文件名形如 `campusflow-{mode}-{YYYYMMDD}.{format}`。

### 12.6 隐私与排除内容

导出不会包含：

- 任务描述、截止备注；
- 资料原文、片段或引用摘录；
- 教师、教学班；
- 发布方与链接。

ICS 说明：

- 只有日期的截止按全天事件处理；
- 计划模式导出时间块，排除缓冲、孤立与取消的块；
- 固定日程需要显式勾选后才展开，不写重复规则；
- ICS 只是草案，不会自动写入外部日历；
- 接受新草案后重复导入 ICS 可能产生重复事件，请在日历客户端中核对。

### 12.7 导出限制

- 计划模式没有 CSV；
- 没有预览不能下载；
- 草案不能作为导出范围；
- 来源失效的条目会标记并排除；
- 工作空间或计划时区不可读时会拒绝导出。

## 13. 课程路径

课程路径从「设置 → 工具箱 → 进入工具箱 → 进入课程路径」进入，也可以直接访问 `/course-paths`。

页面用于维护培养方案、课程关系、别名与修读状态，并查看关系图、修读顺序、下一步建议与学期试排。它只分析依赖关系，不构成毕业资格或选课审核。

### 13.1 培养方案版本

页面顶部显示当前适用方案：专业、年级、版本标签、方案名称，以及学分上限、课程数、关系数与修读记录数。

新建版本：

1. 填写「方案名称」「专业」「入学年级」「版本标签」（均必填）；
2. 可选填写「每学期学分上限（未知留空）」；
3. 点击「创建方案版本」。

创建后需要确认无误再「设为当前方案」。切换方案只改变当前显示，旧方案数据保留，但不再显示在当前路径中；切换不会迁移旧数据。

注意：当前界面不提供培养方案导入入口，只能手动创建；也不提供删除方案版本的入口。

### 13.2 课程目录

页签「课程目录」用于维护方案内课程。

添加课程：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 课程名称 | 是 | 课程名称 |
| 课程代码 | 否 | 例如 CS301 |
| 学分（未知留空） | 否 | 未知时不填 |
| 开课季节 | 否 | 秋、春、夏、冬可多选 |

课程行可以「编辑」「删除」。被关系引用的课程需要先删除关系才能删除课程。

### 13.3 课程关系

页签「课程关系」用于维护三类关系：

- 强制先修；
- 并修；
- 建议先学。

添加关系：

1. 选择「来源课程（先修/建议）」；
2. 选择「受限课程」；
3. 选择「关系类型」；
4. 可选填写「条件原文」；
5. 点击「添加关系」。

说明：

- 建议先学只作提示，不参与强制排序；
- 强制先修参与拓扑排序；
- 并修与强制先修共同影响“可进入课程”的判断；
- 删除关系会同时影响关系图、修读顺序与下一步判断，界面无法恢复。

### 13.4 别名匹配

页签「别名匹配」用于给课程添加别名，并检查名称能否唯一匹配。

添加别名：

1. 选择「对应课程」；
2. 填写「别名」；
3. 可选填写教学班与学期；
4. 点击「添加别名」。

「解析课程名称」可以输入正式课名或别名，选择教学班与学期后点击「解析名称」，结果显示：

- 唯一匹配；
- 存在歧义；
- 未找到。

别名只用于名称匹配，不会合并课程。

### 13.5 修读状态

页签「修读状态」用于记录课程修读情况。

字段：

- 课程（必填）；
- 状态：已修、在修、待修；
- 学期（可选）；
- 成绩（可选）；
- 已获学分（可选，不自动按课程学分推算）；
- 备注。

说明：

- 系统只采用你填写的成绩与学分，不会自动推算；
- 没有修读记录表示“状态未知”，不表示未修；
- 删除修读记录后，该课程回到状态未知。

填写后点击「添加修读记录」保存。

### 13.6 关系图

「依赖图与来源证据」面板显示课程关系图：

- 强制先修：实线箭头；
- 并修：点划线；
- 建议先学：虚线；
- 成环：高亮加粗，成环节点使用红色虚线框。

节点按强制先修深度分列，节点中显示课程名、代码、学分与修读状态。点击节点可以查看课程详情；点击连线可以查看关系类型、条件原文、来源与原文证据。

如果关系没有可展示的原文证据，页面会提示“不代表关系已被原文确认”。

### 13.7 问题清单

「环、矛盾、缺项与待核对」问题清单始终可见，包含四组：

- 强制先修环；
- 关系类型矛盾；
- 缺项与无法匹配；
- 待核对候选。

空组显示“无”。图完整时显示「图完整」，否则显示「图不完整，不能宣称依赖关系已完整」。问题清单为空不等于依赖绝对正确。

### 13.8 修读顺序与下一步

「强制先修层次」只对强制先修关系分层：

- 能生成完整顺序时显示层次与「已生成依赖层次」；
- 存在成环、缺项或来源矛盾时显示「未生成完整顺序」，只列阻塞原因，不伪造顺序；
- 存在可替换层次时会单独标注。

「下一步建议」显示：

- 可进入的课程；
- 暂未满足条件的课程及未满足条件；
- 建议先学（不阻塞）。

建议先学只作提示；只有强制先修与并修影响“可进入”的判断。

### 13.9 学期试排

「学期试排」按已知开课季节与学分上限试排课程。

字段：

- 每学期学分上限（留空使用方案值）；
- 起始季节（秋季／春季）；
- 最多学期数（可选）。

点击「生成学期建议」后显示：

- 每学期包含的课程与已知学分；
- 未排入的课程及原因；
- 限制说明与使用的假设。

试排只依据强制先修、已知开课季节与学分上限，不构成选课或毕业资格审核。

### 13.10 课程路径限制

- 只分析依赖关系，不构成毕业资格或选课审核；
- 缺少学分、开课学期或课程信息时会明确列出，不补造；
- 建议先学不阻塞；
- 问题清单为空不代表依赖绝对正确；
- 关系图只包含当前方案已确认的正式关系；
- 培养方案需要手动创建，当前没有导入入口；
- 没有删除方案版本的入口；
- 所有删除不可恢复。

## 14. 总览

总览是只读页面，不会修改计划。页面包含四个指标卡：

- 今日时间块；
- 近期截止任务；
- 未完整排入；
- 冲突与风险。

「今日安排」显示下一段时间范围、任务标题、每块时长、已锁定状态与安排理由；没有已接受计划时会提示先生成并接受两周草案。

「近期截止」列出未来 7 天带截止日期的待办任务，显示截止日期、逾期标记、优先级与进度。点击任务可以打开任务页并定位到对应任务。

页面底部按工作空间时区显示时间，并提示当前使用的时区。

## 15. 数据备份、升级与卸载

以下内容适用于桌面版；本地开发版的数据库备份请按 PostgreSQL 的常规方式处理。

### 15.1 导出与导入数据归档

- 菜单「数据 → 导出数据归档…」：默认保存到“文档”目录，文件名形如 `campusflow-20261022-101500.campusflow`。
- 菜单「数据 → 从归档导入…」：导入前会暂停 API 与 Worker，替换现有数据并要求确认；导入前建议先导出当前数据。
- 归档包含数据库、资料原文与校验和，不包含模型密钥等凭据。
- 导入完成后会自动恢复服务。

### 15.2 升级

- 直接安装新版本覆盖旧版本；
- 启动时会自动检查数据库结构，需要时先写入升级前备份；
- 升级前备份位于数据目录 `backups/pre-upgrade-<UTC 时间>/`，包含数据库转储、资料快照与带 SHA-256 的清单；
- 迁移或校验失败会自动恢复；
- 数据库结构比当前应用新时，应用会拒绝启动而不会降级；
- 也可以手动选择「数据 → 检查数据库升级…」。

### 15.3 卸载

- Windows：在“设置 → 应用”中卸载 CampusFlow，或运行安装目录下的 `Uninstall CampusFlow.exe`；
- macOS：把 `CampusFlow.app` 移到废纸篓；
- 卸载默认保留用户数据；彻底删除需手动删除对应的 `%APPDATA%\CampusFlow` 或 `~/Library/Application Support/CampusFlow`；
- 卸载前建议先导出数据归档。

### 15.4 日志与诊断

- 菜单「CampusFlow → 打开日志目录」；
- 菜单「CampusFlow → 保存诊断信息」，导出包含版本、路径、端口、启动阶段与最近日志的诊断文件；
- 日志与诊断中的口令、令牌与模型密钥已脱敏；反馈问题时请附诊断文件，不要直接粘贴数据库口令或 API 密钥。

更完整的安装包核对、Gatekeeper／SmartScreen 处理与平台限制见 [桌面版使用指南](desktop/user-guide.md)。

## 16. 常见问题

### 16.1 登录失败怎么办？

- 本地开发版确认后端已经启动，并使用默认账号 `student` / `campusflow-dev`；
- 如果修改过 `CAMPUSFLOW_LOCAL_USERNAME`、`CAMPUSFLOW_LOCAL_PASSWORD`，使用修改后的账号；
- 后端重启后旧会话会失效，重新登录即可；
- 桌面版自动登录失败时，按登录页顶部提示使用本机账号登录。

### 16.2 页面提示“页面不存在”？

该地址可能已经下线。智能问答、待核对、版本对照与外部日历的页面当前不提供入口，系统会回到总览。请从顶部导航或「设置 → 工具箱」进入现有功能。

### 16.3 资料上传失败怎么办？

- 确认格式为 PDF、DOCX、PNG 或 JPG／JPEG；
- 确认单文件不超过 20 MB、单批不超过 5 个文件；
- 旧版 DOC／DOCM 需要先另存为 DOCX；
- 扩展名与文件内容必须一致；
- 上传超时先点击「刷新」确认是否已建档，不要直接重复上传；
- 网页导入失败时，使用「改为粘贴原文」或「改为上传文件」。

### 16.4 为什么文件显示“重复”？

默认会复用完全相同的已有资料，避免重复建档。如果确实需要重复导入，勾选「允许重复导入相同文件」后再上传。

### 16.5 为什么“开始识别”失败？

- 只有粘贴文本需要点击「开始识别」；文件资料在解析完成后自动准备问答索引；
- 识别需要模型密钥，请到「设置 → AI 服务」检查文字生成与向量检索是否显示“可用”；
- 保存密钥后，前台文字生成与检索能力立即使用新密钥，后台资料处理需要重启应用；问答页面当前没有入口，这不影响本地资料、任务与计划功能；
- 资料已归档时不能开始识别，请先恢复；
- 原文尚未切分或索引作业未准备好时，页面会给出原因，刷新后再试。

### 16.6 识别出了候选，为什么不能确认？

候选事项需要人工核对，但待核对页面当前暂不提供入口。识别结果只说明候选已经生成，不能在界面中逐字段修正、确认或转成正式任务。请先在「任务」页手动创建需要执行的任务；等页面恢复后再处理候选。

### 16.7 为什么计划没有时间块？

按顺序检查：

1. 设置中是否至少有一个每周可用时段；
2. 任务是否未完成并填写了预计耗时；
3. 任务截止、依赖是否导致无法排入；
4. 区间是否太短或容量是否太小；
5. 是否使用了“缺失耗时”等假设。

页面中的「未完整排入的任务」和「检查覆盖与限制」会给出具体原因。

### 16.8 计划有冲突或未排入怎么办？

- 在预览中查看冲突类型、风险标记与建议；
- 调整可用时间、容量、任务耗时、优先级或截止；
- 使用「保留锁定块重排」或「生成本地调整草案」；
- 新草案仍需接受后才生效；
- 不要为了消除提示而删除任务；未排入信息本身就是需要处理的信号。

### 16.9 为什么没有收到提醒？

- 提醒不是后台定时推送，需要打开提醒页或发生相关操作时才会同步计算；
- 检查默认规则是否暂停或停用；
- 检查该任务是否有单独规则被暂停；
- 已完成或已取消的任务不会提醒；
- 只有日期的截止不会补造具体时刻；
- 没有提醒不代表没有待办或冲突，请以任务列表和计划为准。

### 16.10 为什么导出按钮不可用？

- 必须先点击「预览」，预览成功后才能「下载」；
- 没有勾选任务或没有选择已接受计划时不能导出；
- 计划模式只能导出 ICS，不能导出 CSV；
- 范围、格式、选项或勾选发生变化后需要重新预览；
- 一次最多导出 500 个任务。

### 16.11 下载时提示“范围已变化”？

预览生成后，导出范围或选项发生了变化，旧预览已失效。重新点击「预览」，确认最新内容后再下载。

### 16.12 为什么引用无法验证？

- 原文件可能已被删除、归档或版本被替代；
- 引用的片段可能已被改写；
- DOCX 与网页只能在片段层面定位，不能直接渲染原文件；
- 请打开「查看原文」确认引用位置；无法定位时不要把该引用当作依据。

### 16.13 课程路径为什么不生成修读顺序？

常见原因：

- 强制先修关系成环；
- 课程缺项或无法唯一匹配；
- 关系类型矛盾；
- 来源候选仍待核对。

页面会显示具体阻塞原因，并且不会伪造完整顺序。先处理问题清单中的条目，再重新查看。

### 16.14 时间显示不对怎么办？

- 检查「设置 → 时区」是否为实际时区；
- 业务时间按工作空间时区解释，不是浏览器本地时区；
- 只有日期的截止不会显示具体时刻；
- 夏令时缺失或重复时刻会明确报错，需要调整输入。

### 16.15 数据在哪里？如何迁移？

- 桌面版数据在用户数据目录，见 [桌面版使用指南](desktop/user-guide.md)；
- 使用菜单「数据 → 导出数据归档…」与「数据 → 从归档导入…」在机器之间迁移；
- 归档不包含模型密钥等凭据，导入后需要重新配置密钥。

## 17. 已知限制

当前版本需要了解的限制：

1. 智能问答、待核对、版本对照与外部日历没有前端入口，相关操作不能在界面完成。
2. 候选事项不能在当前界面确认、忽略或转成正式任务。
3. 提醒不是后台定时推送；关闭应用期间不会发送通知。
4. 计划模式不提供 CSV 导出。
5. 外部日历的 Google 真实账户写入尚未验证；导出只生成 ICS 草案，不直接写入日历。
6. 课程路径的学期试排不构成选课或毕业资格审核。
7. 只有日期的截止不会补造具体时刻；相对日期或缺失信息会保留待核对提示。
8. DOCX 与网页不能直接渲染原文件，只能查看片段与定位。
9. 子任务仅支持一层。
10. 本地开发版使用单用户随机会话，不是生产级身份系统；共享部署前必须替换默认凭据并配置生产会话存储。
11. 桌面安装包当前未签名与公证，干净机器验收尚未完成；不能把安装成功当作发布验收结论。
12. 删除资料后，相关引用不再可验证；删除前请查看影响预览。
