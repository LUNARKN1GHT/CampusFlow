# Q001 中文检索与回答评测准备样本

登记编号 `CF-JSON-001`，版本 `q001-preparation-v1`。全部内容由项目人工构造，不包含真实学生资料、群聊或账户信息；使用范围为项目内部评测，登记见 [registry.csv](../../registry.csv)。

[cases.json](cases.json) 包含 11 个原文片段和 9 个问题。每个片段保存编号、工作空间／学期／课程／教学班、有效状态、合成定位及正文。每个问题保存适用范围、前三条检索结果的检查范围、相关片段、应回答的事实与逐字证据、不确定原因及回答类型。

| 问题编号 | 检查目标 |
| --- | --- |
| deadline-a / deadline-b | 同名课程不同教学班不能串用；另备旧学期、其他工作空间和已删除片段作干扰 |
| submission-paraphrase | 中文不同问法仍应找到提交方式；本轮只准备标注，未测真实检索 |
| missing-year-time | 不从学期猜年份，不补具体截止时刻 |
| conflicting-notices | 两份通知并列展示，缺替代声明不能擅自选新日期 |
| partial-coverage | 已读内容可回答，未导入／未识别部分明确提示 |
| conditional-rule | 保留培训条件、否定与例外限制 |
| no-material / archived-only | 没有有效资料时明确资料不足 |

`manual-transcript` 是人工编写的部分覆盖说明，**不是扫描件，也没有测试图片文字识别（OCR）**。定位也是合成定位，不对应真实附件。

预期事实与证据关系是项目预先编写的答案标注；目前未获得独立人工复核，不代表通用语义判分标准。脚本仅对完全匹配的预设事实和证据集合计分，其他表达进入待人工复核列表。不确定性按预标注原因编号比较，未验证任意自然语言解释是否充分。

运行方式、记录格式、隐私边界和剩余工作见 [Q001 评测准备说明](../../../docs/verification/Q001-preparation.md)。
